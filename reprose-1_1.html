Reprose first-run notes

Reprose is a local-first writing desk. It works as a model-less rich-text editor, but AI continuation requires Ollama to be running and reachable from this browser.

Recommended launch

  • Serve the file from a local folder with python3 -m http.server 8787, then open http://localhost:8787/reprose-0_9b-8-startup-helper.html.
  • If the browser cannot reach Ollama, start Ollama with OLLAMA_ORIGINS='http://localhost:8787,http://127.0.0.1:8787' ollama serve.
  • If OpenWebUI works but Reprose does not, the likely issue is browser access, CORS, or the configured host rather than the model itself.

Safe model settings

8B models

Good for current low/mid hardware. Try 400 tokens, 0.85 temp, 1.10 repeat penalty, and 4096 context.

14B models

Better prose if your machine can tolerate it. Try 500 tokens, 0.80 temp, 1.08 repeat penalty, and 6144 context.

20B models

Use on beefier machines. Try 600 tokens, 0.75 temp, 1.08 repeat penalty, and 8192 context if memory allows.

Storage warning

Projects are stored in browser storage. Export snapshots regularly, because browser storage is still not a substitute for a real external backup.
